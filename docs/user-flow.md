## 0. 로그인 화면 — 재인증

앱 사용 중 Firebase Auth 세션이 만료되거나 설정에서 로그아웃하면 로그인 화면으로 이동합니다. 최초 설치 시에는 이 화면을 거치지 않습니다(온보딩 Page 0에서 로그인).

**동작 흐름:**

| 시나리오 | 결과 |
|---|---|
| Google 로그인 성공 (기존 사용자) | Firestore에서 설정 복원 → 홈 화면으로 이동 |
| Google 로그인 성공 (신규 사용자) | 온보딩으로 이동 |
| 로그인 취소 / 실패 | 에러 메시지 표시, 재시도 가능 |

`MainActivityViewModel`이 `AuthRepository.currentUser` Flow를 구독하다가 `null`(로그아웃)을 감지하면 `signOutEvent`를 emit하고, `MainActivity`가 백스택 전체를 제거한 뒤 이 화면으로 이동합니다.

## 1. 온보딩 — 최초 설정

앱을 처음 실행하면 5단계 온보딩을 거칩니다. 각 페이지에 Lottie 애니메이션을 배치해 딱딱하지 않게 설정을 안내합니다.
<video src="https://github.com/user-attachments/assets/0a4f5a20-84c7-4a9b-8e43-be2aa9971536" controls width="300"></video>

### Page 0 — Google 로그인

Credential Manager 기반 Google 로그인 버튼을 제공합니다.

| 케이스 | 동작 |
|---|---|
| 신규 계정 | 로그인 완료 후 Page 1(닉네임 입력)로 이동 |
| 기존 계정 | Firestore에서 이전 설정 복원 → 온보딩 완료 처리 → 홈으로 바로 이동 |
| 건너뛰기 클릭 | 확인 다이얼로그(`WalkLogDialog`) 표시 — 확인 시 비로그인 상태로 Page 1 진행 |

### Page 1 — 닉네임 입력

닉네임을 입력하면 홈 화면 인사 문구와 설정 프로필에 표시됩니다. 한국어·영어만 허용하고 최대 10자로 제한합니다. 닉네임이 비어 있으면 다음 버튼이 비활성화됩니다.

### Page 2 — Health Connect 권한 요청

걸음 수 읽기 권한을 요청합니다. 거부해도 앱은 계속 사용할 수 있고, 홈 화면에서 다시 요청할 수 있습니다.

### Page 3 — 일일 목표 걸음 수 설정

슬라이더로 하루 목표 걸음 수를 설정합니다. 범위는 5,000~20,000보이며 기본값은 10,000보입니다.

### Page 4 — 알림 설정

피크아워 기반 걷기 알림 수신 여부를 설정합니다.

## 2. 홈 화면 — 오늘의 걷기 현황

<video src="https://github.com/user-attachments/assets/f0b097c2-709b-491f-bc81-533d4e68211b" controls width="300"></video>

홈 화면은 오늘의 걷기 상태를 한눈에 보여주는 대시보드입니다.

**구성 요소:**

- **닉네임 인사**: "OO님, 오늘도 걸어요!" — 설정한 닉네임이 반영됩니다.
- **걸음 수 링**: 오늘 걸음 수와 목표 달성률을 원형 링으로 표시합니다. 걷는 중으로 감지되면 링이 pulse 애니메이션으로 강조됩니다.
- **스트릭 뱃지**: 연속 목표 달성 일수를 표시합니다.
- **날씨 카드**: 현재 기온, 날씨 상태, 오늘 걷기 적합 여부를 안내합니다. GPS 위치를 기반으로 한국(KMA) / 해외(Open-Meteo) 제공자를 자동 선택합니다.
- **지난주 리포트 요약**: 지난주 총 걸음 수와 달성률 카드를 홈에서 바로 확인할 수 있습니다.
- **예보 배너**: 오늘 피크아워 예보를 표시하고, 탭하면 예보 상세 BottomSheet가 열립니다.

**Health Connect 미연결 상태 처리:**

| 상태 | 표시 내용 |
|---|---|
| 권한 미허용 | 권한 요청 카드 |
| HC 미설치 기기 | HC 미지원 안내 카드 |
| 정상 | 전체 대시보드 |

**미션 달성 자동 감지:**

걸음 수가 목표치에 도달하면 자동으로 포인트가 지급됩니다. 하루에 한 번만 지급되며 앱을 재시작해도 중복 지급되지 않습니다.

## 3. 미션 화면 — 오늘의 목표

<video src="https://github.com/user-attachments/assets/80615d15-a408-48ae-9da8-f76dd37a139a" controls width="300"></video>

오늘 달성해야 할 걸음 수 목표와 달성 현황을 카드로 보여줍니다.

**미션 타입:**

| 타입 | 조건 | 보상 |
|---|---|---|
| 일반 미션 | 매일 | 20 포인트 |
| 회복 미션 | 전날 미달성 시 | 20 포인트 |

전날 목표를 달성하지 못하면 다음 날 더 낮은 목표의 회복 미션이 제공됩니다. 회복 미션을 달성하면 스트릭이 유지되고, 실패하면 스트릭이 초기화됩니다.

## 4. 주간 리포트 — 아카이브 & 상세

<video src="https://github.com/user-attachments/assets/34f5408a-a072-4eb0-b41b-701801ab9d5b" controls width="300"></video>

최근 12주의 걷기 기록을 카드 목록으로 모아볼 수 있습니다.

**아카이브:**
- 주별 총 걸음 수, 달성률, 날짜 범위를 카드로 요약합니다.
- 현재 진행 중인 주는 잠금(LOCKED) 상태로 표시됩니다.

**상세:**
- 카드를 탭하면 요일별 막대 그래프와 주간 통계를 확인할 수 있습니다.
- "리포트 공유하기"를 탭하면 주간 요약 이미지를 캡처해 외부 앱으로 공유할 수 있습니다.

## 8. 설정 — 닉네임 & 포인트

<video src="https://github.com/user-attachments/assets/f7a02b39-bb57-486a-be53-4f94f23b3158" controls width="300"></video>

### 프로필 섹션

화면 상단에 이니셜 아바타, 닉네임, 포인트 뱃지를 표시합니다. 로그인 상태이면 계정 이메일도 함께 표시됩니다.

### 계정 섹션

| 상태 | 표시 내용 |
|---|---|
| 로그아웃 | Google 로그인 버튼 표시 — 탭하면 Credential Manager 로그인 진행 |
| 로그인 | 계정 이메일 + 로그아웃 버튼 표시 |

로그아웃하면 `SignOutUseCase`가 Firebase Auth 세션을 만료시키고 DataStore의 `userId`를 초기화합니다. `MainActivityViewModel`이 인증 상태 변화를 감지해 로그인 화면으로 자동 이동합니다.

### 닉네임 수정

닉네임 영역을 탭하면 수정 BottomSheet가 슬라이드업됩니다. 저장하면 홈 화면 인사 문구와 프로필이 즉시 반영됩니다.

### 기타 설정

- 일일 목표 / 회복 걸음 수 조정
- 알림 켜기/끄기
- 라이트 / 다크 / 시스템 테마 즉시 전환

### 프리미엄 테마

리워드 스토어에서 "테마 팩"을 교환한 사용자만 볼 수 있는 토글입니다.

| 상태 | 표시 |
|---|---|
| 미소유 | 토글 비활성화(터치 불가) + "리워드 스토어에서 테마 팩을 교환하면 사용할 수 있어요" 안내 문구 |
| 소유 | 골드 그라디언트 `PREMIUM` 칩 표시 + 토글로 즉시 켜고 끌 수 있음 |

토글을 켜면 앱 전체가 즉시 골드/네이비 프리미엄 팔레트로 전환되고, 홈 화면의 걸음 진행률 링에 샤이머·글로우·궤도 파티클 애니메이션이 추가로 나타납니다. 소유 여부는 `GetRewardRedemptionsUseCase(THEME_PACK)` 조회 결과로 판단하며, 미소유 상태에서는 `SettingsViewModel.togglePremiumTheme()`도 조기 반환되어 토글이 View·ViewModel 양쪽에서 이중으로 막혀 있습니다.

## 10. 리워드 — 보상 시스템

<video src="https://github.com/user-attachments/assets/6212c039-a980-411a-a363-63c0b776fed1" controls width="300"></video>

바텀 내비게이션의 리워드 탭에서 접근합니다. 별빛 파티클 배경 위에 4개의 카드가 있으며, 그중 3개는 실제 기능으로 동작하고 레벨 보상만 잠겨 있습니다.

| 카드 | 상태 | 이동 화면 |
|---|---|---|
| 포인트 적립 | 활성 | Points History (Compose, 네이티브) |
| 뱃지 컬렉션 | 활성 | Badge Collection (Compose, 네이티브) |
| 리워드 스토어 | 활성 | Reward Store (React Native) |
| 레벨 보상 | 잠김 | — |

**현재 포인트 적립 기준:**

| 행동 | 포인트 | 중복 방지 |
|---|---|---|
| 일일 미션 달성 | +20 | 하루 1회 |
| 회복 미션 달성 | +20 | 하루 1회 |

### 포인트 적립 내역

미션 적립뿐 아니라 리워드 스토어에서 교환에 쓴 포인트도 하나의 타임라인으로 보여줍니다. 각 항목의 사유는 `PointsLedgerEntry.reason`(`MissionType.name` 또는 `REDEEM_{rewardId}`)을 UI 문자열로 매핑해 표시합니다.

### 뱃지 컬렉션

트로피 캐비닛 형태의 성취 갤러리입니다. 상단에 "보유 뱃지 X/Y" 진행률 헤더가 있고, 2x2 그리드로 골드 워커 뱃지 1칸 + "???" 미스터리 플레이스홀더 3칸을 보여줍니다. 보유한 뱃지는 샤이머 애니메이션이 도는 골드 메달리온으로, 미보유 상태는 어두운 메달 + 자물쇠 아이콘으로 표시합니다. 미스터리 칸은 점선 원 테두리만 그려 "추후 추가될 뱃지"라는 기대감을 남깁니다.

보유 시 **홈 화면 인사 문구 옆에도 🥇 골드 워커 칩이 함께 노출**되며, 칩을 탭하면 이 화면으로 바로 이동합니다 — 뱃지를 어디서도 확인할 수 없다는 문제를 홈 진입 시점에 해결합니다.

### 리워드 스토어 (React Native Brownfield)

[Toss SLASH23 발표](https://toss.tech)의 브라운필드 패턴을 참고해 `@callstack/react-native-brownfield`로 통합한 React Native 화면입니다. 네이티브 앱과 별도 Gradle/Node 루트(`reward-store-rn/`)에서 개발되고, `RewardBridgeModule`(`app` 모듈)을 통해 네이티브 포인트/인증/테마 도메인과 통신합니다.

**진입 시 로그인 상태에 따른 분기:**

| 상태 | 화면 |
|---|---|
| 비로그인 | 상단에 "로그인이 필요해요" 배너 + 로그인하기 버튼. 카탈로그는 계속 보이고 눌러볼 수 있음 |
| 로그인 | 배너 없이 정상 카탈로그 |

**카탈로그 (4종, 비용 순):**

가격과 판매 여부는 Firestore `rewardCatalog` 컬렉션에서 실시간으로 받아오므로, 관리자가 콘솔에서 값을 바꾸면 앱 업데이트 없이 다음 화면 진입 시 바로 반영됩니다. 아래 표는 기본값(오프라인 폴백 값과 동일)입니다.

| 상품 | 기본 비용 | 교환 시 효과 |
|---|---|---|
| 골드 워커 뱃지 | 200P | Room + Firestore에 교환 기록 → 뱃지 컬렉션·홈 칩에 즉시 반영, 재설치해도 유지 |
| 아메리카노 쿠폰 | 500P | Firestore에 쿠폰 코드 발급 (`WALK-XXXXXX`) |
| 기부 500P | 500P | 교환 기록의 포인트 합산이 총 기부액 |
| 테마 팩 | 800P | 프리미엄 테마 즉시 활성화 (설정에서 이후 껐다 켰다 가능) |

**"교환하기" 탭 시 3가지 결과:**

1. `SUCCESS` — 포인트 차감, 잔액 갱신, (쿠폰/테마 상품이면) 해당 부수 효과 실행
2. `INSUFFICIENT_BALANCE` — "포인트가 부족해서 교환할 수 없어요" 알럿
3. `SIGN_IN_REQUIRED` — "로그인이 필요해요" 알럿 → 로그인하기 선택 시 네이티브 로그인 화면으로 이동(`navigateToSignIn` 브릿지)

**쿠폰 등록/사용:**

아메리카노 쿠폰을 교환하면 화면 하단에 "보유 쿠폰" 목록이 나타납니다. 코드를 탭하면 모달이 뜨고, 코드를 크게 보여준 뒤 "사용 완료로 표시" 버튼으로 매장에서 실제 사용한 뒤 상태를 `USED`로 전환합니다. 이미 사용된 쿠폰은 목록에서 흐리게 표시되고 다시 열리지 않습니다.

화면 팔레트(라이트/다크/프리미엄)는 네이티브 `getThemeState()` 브릿지로 현재 앱 테마를 읽어와 결정하므로, 네이티브 쪽에서 프리미엄 테마를 켜면 리워드 스토어도 같은 골드/네이비 팔레트로 렌더링됩니다.

**이벤트/프로모션 코드 등록:**

스토어 상단 "코드 등록" 버튼을 누르면 코드 입력 모달이 뜹니다. 마케팅/이벤트에서 외부로 받은 코드를 직접 입력해 포인트를 받는 기능으로, 스토어 카탈로그 교환과는 별개의 흐름입니다(코드는 관리자가 Firebase 콘솔에서 발급).

1. `SUCCESS` — "코드 등록 완료" 알럿에 지급된 포인트 표시, 잔액 갱신
2. `ALREADY_REDEEMED` — "이미 등록된 코드" 알럿
3. `INVALID_CODE` — "유효하지 않거나 만료된 코드예요" 알럿
4. `SIGN_IN_REQUIRED` — "로그인이 필요해요" 알럿 → 로그인하기 선택 시 네이티브 로그인 화면으로 이동

**예정 기능:** 레벨 시스템
